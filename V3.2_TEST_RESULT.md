## v3.2 Coverage

The release verifies:

- verifier-controlled build execution;
- verifier-controlled test execution;
- build-before-test ordering;
- explicit build failure containment;
- explicit test failure containment;
- structured execution results;
- conversion of execution results into verifier evidence;
- evidence schema validation;
- DFA-controlled evidence submission;
- evidence replay protection;
- adversarial forged-success rejection;
- evidence mutation rejection;
- USER_REQUIRED containment;
- preservation of the existing v2.4–v3.1 control boundary.

## Release Boundary

A successful build and test run does not produce COMPLETE by itself.

Integration and smoke criteria remain BLOCKED until those verification stages are
implemented. Therefore v3.2 cannot falsely represent build/test success as
full-system verification.

## Limitations

v3.2 does not provide:

- AWS deployment;
- live cloud verification;
- integration verification against deployed infrastructure;
- smoke verification against a live system;
- unrestricted shell execution;
- unrestricted package installation;
- arbitrary network access;
- credential management;
- production-scale guarantees;
- a formal proof of all possible agent behavior.
